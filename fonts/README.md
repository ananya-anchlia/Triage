# Local fonts

Downloaded from Google Fonts on 2026-10-11. All three families are distributed under
the SIL Open Font License; the unmodified upstream licenses are included here.

- Nunito Sans (Latin, variable weight): body, controls and numbers, weights 400–800.
- Varela Round (Latin, regular): headings and decorative window titles.
- Silkscreen (Latin, regular): small simulated-data tags only.

The WOFF2 files are served locally with `font-display: swap`. No Google Fonts request
is made by the app. Segoe UI and system sans-serif fonts remain the fallbacks.

Upstream family and license sources:

- https://github.com/google/fonts/tree/main/ofl/nunitosans
- https://github.com/google/fonts/tree/main/ofl/varelaround
- https://github.com/google/fonts/tree/main/ofl/silkscreen
